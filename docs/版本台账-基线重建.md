# 版本台账 · 基线重建（2026-11-13）

## 背景

Windows 实测：v2.0.7 正常，v2.0.8 起出现「几乎铺满窗口、四周一圈蓝边、中间纯白」
的白块；出现/消失与底部面板的自动隐藏计时同步，白块期间底部面板看不见。

对比 v2.0.7（`53c658ac`）与 v2.0.8（`642453bd`）全部 106 个源文件，只差 2 个文件
95 行，且不含任何绘制覆盖层的代码 → 判定问题来自 2.0.8 之后的某一批界面改动
（用户下载的 2.0.8 很可能是 06:28 那批，含「定时关闭在画面上可见」的覆盖层）。

**处置方式：以 v2.0.7 源码树为干净基线，逐批回加 2.0.8 之后的功能，每批单独出包，
由用户逐版实测定位。**
