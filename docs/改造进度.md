## 二、每一步到底改了什么

### 第 0 步 · token 体系 ✅

- `lib/core/theme/app_colors.dart`：基底/表面/三级文字/强调/状态色/分割线
- `lib/core/theme/app_typography.dart`：`title` / `body` / `caption` + OSD 专用 `osdNumber` / `osdCaption`
- `lib/core/theme/app_density.dart`：面板高、台标、按钮直径、行高、间距、圆角，按 TV/桌面/手机三档；`DeviceProfileScope` 同时下发用户字号滑块系数
- 数值全部按 **1.0.201 实测观感校准**（面板大字 24、节目行 14.5、台标 128/92、按钮 48/44），先贴合现状再谈优化

### 第 1 步 · 焦点协调器 🟡

`lib/core/focus/` 下三个文件（`focus_region` / `focus_coordinator` / `safe_focus`）已入库。

**为什么不接**：1.0.201 已经是「单根焦点 + 全局按键分发」结构，没有旧版那些"每个面板各挂一套 onKeyEvent、抢焦点"的补丁，`player_screen.dart` 里一处分发就能覆盖面板/列表/EPG/数字输入。此时再插一层协调器，等于把一个能用的东西重写一遍，收益是"更整齐"，代价是全局焦点回归风险。按"简洁快速"原则先不动，如果后续真的出现焦点互抢再加。

### 第 2 步 · token 全量替换 ✅

- 底部面板：字号、间距、按钮尺寸、圆角已全部走 token
- 频道列表 / EPG：新增三个列表专用槽 `listHeader` / `listItem` / `listSub`
  （18 / 16 / 12.5），把抽屉标题、分类名、频道名、频道号、节目名、
  节目时间、直播中徽章、描述等 14 处字面量全部换掉。
  三档目前取同一组值：列表是「密度优先」界面，字号和行高是一对
  （`AppDensity.listRowHeight`），单改字号会改变一屏频道数。
  以后要按电视/手机差异化，只改这张表 + 对应行高即可。

### 第 3 步 · ghost 统一按钮 ✅（本轮）

`lib/core/widgets/ghost_button.dart` 重写：

- 尺寸只来自 `AppDensity.buttonSize`，组件外不能传尺寸；`role` 决定倍率（普通 1.0 / 强调 1.25 / 主控 1.2）
- 新增 `selected`：外部高亮（遥控器 ←/→ 选中）与键盘焦点、鼠标悬停**共用同一套视觉**——白描边 + 细发光 + 8% 白底
- 修掉旧实现的一个真 bug：原来用 `Focus.of(context)` 判断焦点，拿到的是**祖先**节点，按钮自己聚焦时永远返回 false，等于焦点态从没生效过。现在改为自持 FocusNode 监听
- Tooltip 只在桌面端启用（电视/手机没有悬停，提示反而挡画面）
- 桌面端 tooltip 自动追加真实快捷键：`暂停 (空格)` / `静音 (M)` / `全屏 (F)` / `录制 (R)`

接入点：

- `lib/widgets/bottom_program_panel.dart`：删掉 `IconButton` + `_wrapSelected` 蓝框高亮，全部换 `GhostButton`
- `lib/player/widgets/source_stepper.dart`：左右箭头同样换掉，消除"箭头蓝框、别的钮白框"的混搭

### 第 4 步 · 底部面板重排 ✅

`lib/widgets/bottom_program_panel.dart`：悬浮卡片式面板（深色渐变 + 圆角 + 细描边 + 投影）、台标不贴左缘、信息区可挤压截断、`‹ 线路 n/m ▾ ›` 步进器（点中间弹线路菜单跳选）、分组竖线（电视/桌面有，手机不画）。

### 第 5 步 · 换台防抖 + 数字输台 ✅

- 换台两段式：先只更新 OSD 预览，**450ms 内不再按键才真正切流**，连续上下键不再把中间频道全都拉一遍流
- 数字输台：2s 自动提交、每次按键先清缓冲防残留、`startsWith` 部分匹配给灰字提示、无匹配提示"无此频道号"

### 第 6 步 · 播放哨兵 ✅ 原生已有

1.0.201 自带投屏看门狗、有声无画检测、软→硬分级重载与重载上限提示，不重复实现。

### 第 7 步 · 投屏态 + 安卓浮窗 ✅

- 面板 castMode：信息区换「正在投屏 · 设备名」，按钮组换播放/静音/旋转/断开
- 安卓：`supportsPictureInPicture` + 前台服务 + 通知栏音频卡片（上一台/暂停/下一台/关闭），退后台自动进小窗；相关原生代码由 CI 在 `flutter create` 后注入，Dart 侧门面是 `lib/services/pip.dart`

### 第 8 步 · Windows 快捷键 ✅ 原生已有

已注册：空格=暂停、↑↓=换台（走防抖）、←→=换源、M=静音、F/F11=全屏、R=录制、C=频道、E=节目单、S=设置、数字=跳台、Esc=层级返回。

> 注意：`R` 实际是**录制**，不是重载。重载按钮没有快捷键，别在提示里写错。

### 第 9 步 · 设置页双栏（方案 4.1）✅

- 顶部四/五 Tab → **左栏分类 + 右栏内容**：节目源 / EPG / 播放器 / 系统 / 说明
- 左栏宽 156dp，选中项走强调色胶囊；**整栏只占一个焦点停靠点**：
  上下切分类、右键进内容——比让 5 个分类各自进焦点遍历更好预测
- 手机窄屏（内容宽度 < 620）自动折成顶部横滑胶囊，左右切分类、下键进内容
- 面板表面从 `Colors.black87` 换成 `AppColors.overlay` + 1px `stroke` 描边
  （方案 3.8 三件套第二件），在暗画面下能看出边界
- 内容页仍是"只构建当前页"，切分类不会把隐藏页的控件留在焦点树里

### 双域选台：左侧列表 电视 / 电台 ✅（方案 12.6）

左侧频道列表顶部两个胶囊签 `📺 电视 | 📻 电台`（带数量）：

- **电台域是跨源聚合**：`我的电台` 在前，其后是内置精选五个分组。
  切标签**不动当前节目源**，点哪个台播哪个台（`playChannel`），
  正在播的台高亮。以前"翻电台"必须切源、切源就会打断正在看的电视，

- **加台就在手边**：电台签右上角 + 空态按钮直接开「在线电台」搜索，
  加完立刻出现在 电台 → 我的电台，不用绕去设置。
- **收藏按域分流**：电视收藏、电台收藏各看各的，一列里不混两种东西。
- **遥控器**：第一级按左键切域（右键留给"进分类"），第二级左键回上一级。
- **记忆**：打开抽屉时跟随"正在播的那一类"切域，但只在频道变了时切——
  手动翻到电台后关掉再开，不会被拽回电视。

**12.6 剩余三项已补齐**：

- **电视伴音自动匹配**：拿当前电视源的频道名去电台源里找同名独立
  音频流（`RadioCatalog.withTvCompanion`），匹配到的才进「电视伴音」组，
  台标/EPG 标识继承电视。只做规范化同名（去标点、CCTV 写法统一、
  去「伴音/广播/FM」），不做模糊包含——「新闻台」这类泛名一模糊就配错。
  切源/刷新频道后重算。
- **菜单键一键切域**：左侧列表打开时菜单键在电视/电台间切换
  （此前该键空闲）。
- **双域独立记忆**：电视、电台各存一份上次频道，另存"上次所在域"；
  启动恢复「上次所在域 + 该域上次频道」。

### 播放态视觉（方案 12.3 第二档）✅

电台没有画面，最容易出的误会是"是不是没播"。三处同时给信号：

| 位置 | 元素 |
|---|---|
| 播放区 | 台标 → **25 根起伏波柱**（`AudioWave`）→ 台名 → 呼吸点 +「正在收听」+「音频流」小标 → 当前节目 |
| 底部面板 | 分辨率位换成「🎧 音频直播」徽章（4 根跳动小条），暂停时波柱压平、文案变「已暂停」；电台不显示「线路 x/y」这类无意义项 |
| 频道列表 | 圆形台标 + 电台分组，与电视同一套焦点/收藏 |

波形走**两级**，能真就真：

1. **真实波形（首选）**：电台起播前给 libmpv 设 `lavfi-complex`

   ```
   [aid1]asplit[ao][sp];[sp]showwaves=s=480x96:mode=cline:rate=25:colors=0xFFFFFF[vo]
   ```

   音频一路照常出声（`[ao]`），一路交给 ffmpeg 的 `showwaves` 画成波形
   并作为视频输出（`[vo]`）。mpv 因此产生真实视频帧，Flutter 侧拿
   `VideoController` 的纹理贴在台标下方——**跟着真实 PCM 起伏**，
   不需要自己抓音频做 FFT。滤镜链建不起来（mpv 未编 showwaves 等）
   会在 6 秒内报错，自动摘掉滤镜重开同一路流，退回第 2 级。

2. **缓动波形（兜底）**：`AudioWave` 自绘。每根柱独立相位/速度/包络，
   上升快回落慢（14:5 阻尼），起播从 0 涨起、暂停平滑收平后停表。
   只在 paint 阶段算高度，60fps 成本可忽略。

底部面板与「音频流」小标上的 3~4 根迷你条始终用第 2 级（几像素高，
没必要为它开一路纹理）。

### ICY 曲目（正在播什么）✅

libmpv 把 Icecast 的 `StreamTitle` 映射到 `media-title` 属性，
`observeProperty` 订阅它的变化即可：换歌、换节目会自动更新，
不需要轮询。显示位置：

| 位置 | 表现 |
|---|---|
| 电台大屏 | 台名下「● 正在播」+ 曲目/节目名（没有元数据就不占位） |
| 底部面板 | 第三行「♪ 歌名 - 歌手」，无元数据时退回分组名 |

若某个台不发 ICY（不少省市台只发纯音频），自动回落到 EPG 节目名；
两者都没有就只显示台名，不留空行。

### 设置里卡顿（方案第十节）✅

用户实测：播放中点设置里的开关/选项，画面卡一下。三处根因：

| 根因 | 修法 |
|---|---|
| `app.dart` 把 `Consumer<PlayerController>` 包在整个 MaterialApp 外：任何 notify 都重建 ThemeData → 全树重排 | 拆出 `_OmiMaterialApp`，只有 `settingsNotifier` / `tvModeNotifier` 变化时局部重建 MediaQuery 包装层 |

| 每次变更 `getInstance` + 19 次 `setXxx`，Windows 上 shared_prefs 每次整文件重写 | 写盘去抖 250ms，退出前 `flushSettings()` 补写 |
