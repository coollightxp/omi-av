## 第 0 步：新建 token 体系（一切的地基，约半天）

```

**app_density.dart 骨架**（核心，所有尺寸从这里取）：

```

**app_typography.dart**：`title/body/caption` 三语义 × 三档（电视 18/15/13，桌面 15/13/11，手机 13/10.5），并注入 `ThemeData.textTheme`。

**验收**：项目能编译；随便挑一个面板把写死的字号换成 token，显示不变。

## 第 1 步：焦点协调器（最优先，约 1-2 天）

**新建文件**：

```
lib/core/focus/
├── focus_region.dart       # 枚举
└── focus_coordinator.dart  # 唯一焦点总管
```

**focus_coordinator.dart 骨架**：

```dart
enum FocusRegion { player, channelList, epg, bottomPanel, exitCard, numberInput }

class FocusCoordinator {
  FocusRegion _current = FocusRegion.player;
  FocusNode? _archived; // 面板打开前播放器区的焦点存档

  FocusRegion get region => _current;

  /// 面板打开：存档 → 切区
  void open(FocusRegion r, {required FocusNode newFocus, FocusNode? from}) {
    if (_current == FocusRegion.player) _archived = from ?? _archived;
    _current = r;
    safeRequestFocus(newFocus);
  }

  /// 面板关闭：回存档
  void close() {
    _current = FocusRegion.player;
    if (_archived != null) safeRequestFocus(_archived!);
    _archived = null;
  }

  /// 唯一按键入口：挂在整个 App 最外层 Focus 的 onKeyEvent
  KeyEventResult onKey(FocusNode node, KeyEvent event) {
    switch (_current) {
      case FocusRegion.player:      return _handlePlayerKey(event);   // handled
      case FocusRegion.channelList: return _handleListKey(event);
      case FocusRegion.epg:         return _handleEpgKey(event);
      case FocusRegion.numberInput: return _handleNumberKey(event);
      // ... 每个分支最终必须 return handled 或 ignored(仅放行给系统)
    }
  }
}

/// 防"未挂载就 requestFocus 静默失败"
void safeRequestFocus(FocusNode node) {
  WidgetsBinding.instance.addPostFrameCallback((_) => node.requestFocus());
}
```

**接入方式**：App 最外层包一个 `FocusScope`，`onKeyEvent` 全部转发给协调器；各面板**删掉自己所有的 onKeyEvent/requestFocus 补丁**，只保留"打开时调 `coordinator.open(...)`、关闭时调 `close()`"。

**迁移顺序与每面板 checklist**：

| 顺序 | 面板 | 删除 | 保留/新增 |
|---|---|---|---|
| 1 | 频道列表 | 自带按键处理、自带 requestFocus | open/close 两行 |
| 2 | EPG 右面板 | 同上 | 同上 + 预约键走协调器 |
| 3 | 底部面板 | 同上 | 同上 |
| 4 | 退出卡片 | 同上 | 返回键路由进协调器 |
| 5 | 数字输入 | 数字键散落处理 | 输入态作为独立 region（返回键=取消输入，优先级在这定义） |

**验收**：随机快速"开面板→返回→开另一个→返回"20 组，每个方向键恰好触发一个动作、焦点总能回到原频道。

## 第 5 步：换台防抖 + 数字输台三细节（约半天）

**防抖**（进协调器的 `_handlePlayerKey`）：

```dart
Timer? _tuneDebounce;
void requestTune(Channel ch) {
  showChannelOsd(ch);            // 立即只更新 OSD
  _tuneDebounce?.cancel();
  _tuneDebounce = Timer(450ms, () => playerService.play(ch)); // 停顿才切流
}
```

**数字输台**（numberInput region）：
- 缓冲 `buffer` + 自动提交 `Timer(2s)`（显示倒计时进度）
- 每次按键：**先清缓冲重置 Timer 再记新数字**（防残留误提交）
- 部分匹配：`channels.where(number.startsWith(buffer))` 取第一个，灰字提示 `→ CCTV-1 综合`；无匹配提示"无此频道号"
- 输入态下返回键 = 取消输入（在协调器 numberInput 分支里定义，不触发退出卡片）

## 第 6 步：播放哨兵 + 分级重载（约 1 天）

**新建**：`lib/player/playback_watchdog.dart`

```dart
class PlaybackWatchdog {
  Timer.periodic(3s, (_) {
    if (直连流) {
      if (state == playing && position 未变) _stallCount++;
      if (_stallCount >= 2) reload();                 // 软→硬
    } else { // WebView
      injectJs('read currentTime');                   // 路一
      两次 currentTime 相同且非 paused → reload();
      // JS 读取失败时降级帧比对（路二，截图比对）
    }
    if (_reloadCount >= 设置的重载次数) showFailedPanel(); // [重试][换线路]
  });
}
```

- 软重载：WebView 调 JS 让页面播放器重连；直连流重开当前 Media
- 硬重载：WebView 整页 reload；直连流换下一个源
- 手动重载按钮 = 立即走一遍"先软后硬"
- **验收**：把 WebView 断网模拟黑屏，10 秒内自动触发重载；重载超限后出提示而不是无限转圈

## 第 7 步：投屏态模板 + 安卓自动浮窗（约 1 天）

- 底部面板加第二份配置 `castMode`：信息区换"正在投屏 · 设备名"，按钮列表换 `[play/pause, mute, rotate, disconnect]`
- 投屏服务收到连接 → 面板切 castMode + 顶部横幅（含断开）；断开 → 按设置回频道态或等待
- 安卓：监听 `AppLifecycleState`，`paused` 且非正常退出 → 显示悬浮窗（系统悬浮窗权限）；设置页加开关"退到后台显示悬浮窗"；浮窗带 暂停/关闭/回主程序 三钮
- **验收**：投屏手机画面到盒子，面板正确切换且断开可用；切后台出浮窗、开关关闭后不出

## 第 8 步：Windows 快捷键（约半天）

在协调器 player 分支注册（或 `CallbackShortcuts`）：

空格=暂停 · ↑↓=换台(走防抖) · ←→=换源 · M=静音 · R=重载 · F/Esc=全屏 · 数字=跳台

按钮 tooltip 标注对应快捷键（第 3 步组件已支持）。

## 总验收清单

- [ ] 焦点：随机开关面板 20 次，方向键恰好一个响应、焦点回原处
- [ ] 手机：面板 ≤ 屏高 1/6，列表一屏 ≥10 频道，台标不贴左缘
- [ ] Windows：分组竖线 + tooltip 快捷键 + 全键盘可完成所有操作
- [ ] WebView 黑屏 10 秒内自动重载，超限有提示
- [ ] 投屏收发全程面板状态正确，断开可达
- [ ] 三端截图横向对比：同一套视觉语言，无突兀项
